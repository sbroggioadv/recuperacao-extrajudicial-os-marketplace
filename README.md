# Recuperação Extrajudicial OS — Marketplace

Preparação da recuperação extrajudicial pelo advogado do devedor ou do credor, inclusive produtor rural, com limites e revisão humana.

## Instalação no Cowork

No Claude Desktop, abra a área de plugins do Cowork, escolha adicionar um marketplace e informe `https://github.com/sbroggioadv/recuperacao-extrajudicial-os-marketplace`. Instale **recuperacao-extrajudicial-os**, abra uma conversa e execute `/recuperacao-extrajudicial-install` para configurar; use `/recuperacao-extrajudicial-master` para conduzir o trabalho.

## Escopo e limites

O plugin oferece 24 skills e 12 comandos. O advogado revisa os documentos e as fontes antes do uso. O plugin não negocia, assina ou protocola automaticamente e não substitui decisões do Poder Judiciário. Consulte o [README do plugin](recuperacao-extrajudicial-os/README.md).
